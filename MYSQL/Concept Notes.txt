Constraints:
| Constraint      | Description                                                               | Example                                               |
| --------------- | ------------------------------------------------------------------------- | ----------------------------------------------------- |
| **PRIMARY KEY** | Uniquely identifies each record in a table (no duplicates, no NULLs).     | `EmpID INT PRIMARY KEY`                               |
| **FOREIGN KEY** | Ensures data in one table matches values in another table (relationship). | `FOREIGN KEY (DeptID) REFERENCES Departments(DeptID)` |
| **UNIQUE**      | Ensures all values in a column are unique (can have one NULL).            | `Email VARCHAR(100) UNIQUE`                           |
| **NOT NULL**    | Ensures a column cannot have a NULL value.                                | `FirstName VARCHAR(50) NOT NULL`                      |
| **CHECK**       | Restricts values based on a condition.                                    | `Salary DECIMAL(10,2) CHECK (Salary > 0)`             |
| **DEFAULT**     | Assigns a default value if no value is given.                             | `Country VARCHAR(50) DEFAULT 'India'`                 |

Joins:
| Join Type       | Description                                           | 
| --------------- | ----------------------------------------------------- | 
| INNER JOIN      | Only rows that match in both tables                   | 
| LEFT JOIN       | All rows from left table + matching rows from right   | 
| RIGHT JOIN      | All rows from right table + matching rows from left   |
