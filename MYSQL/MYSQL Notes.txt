Question:
Create a table Students with the following columns:
student_id (INT, Primary Key)
first_name (VARCHAR(50))
last_name (VARCHAR(50))
age (INT)
grade (VARCHAR(10))

Answer:
CREATE TABLE Students (
    student_id INT PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    age INT,
    grade VARCHAR(10)
);
What PRIMARY KEY means:
A primary key is a column (or a set of columns) that uniquely identifies each row in the table.
Rules of a primary key:
Uniqueness → No two rows can have the same value in the student_id column.
Not NULL → A primary key cannot be NULL, because every record must have an identifier.

So in this table:
student_id uniquely represents each student.
Even if two students have the same first_name, last_name, or grade, their student_id will always be different.

| student_id | first_name | last_name | age | grade |

select * from Students where first_name like "A%";-This filters the first_name starting with A.
select * from Students where first_name like "%A";-This filters the first_name ending with A.
select * from Students where first_name like "%I%";-This filters the first_name that has i in the middle
select * from Students where first_name like "__h%";-This filters the first_name that has the third letter i
(All these are not case sensitive we can either use I or i)

3)primary (In college as well as department our name should be present-combination of not null and unique)
4)foreign key -link between more than one table
5)check condition -specify some condition like age>18
In some cases the age will definitely will be less than 17 for people studying in school so when we give some wrong value for example 23 it will throw an error.
