4)Method overloading
-Same method name with different parameters
For example:
If in the name of sum we have two methods that is:
        static int sum(int a,int b) {
		return a+b;
	}
	
	static int sum(int a,int b,int c) {
		return a+b+c;
	}
In the main:
                int result = sum (12,5);
		System.out.println("Add result is:"+result);
		//overloading
		int result1 = sum (12,5,7);
		System.out.println("Result from overloading:"+result1);

Based on the number of parameters we have given it will match with the relavant method and execute.
In the above case 2 parameters or 3 parameters.
