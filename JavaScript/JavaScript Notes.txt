function:
*function is a block of code that performs a specific task.
*function avoids code repetition
*Types of function:
1)named function
-A function that has a name and can be called by that name is called named function
Example:
function add(a, b) {
    return a + b;
}
add(5, 3);   // 8

2)anonymous function (without a name)
-A function that does nat have a name and is usually stored in a variable
-function without a name
-Example:
let greet = function () {
    console.log("Hello!");
};
greet();//Hello!

3)arrow function
-A shorter syntax for writing functions
-Example:
let multiply = (a, b) => {
    return a * b;
};
console.log(multiply(2,3));//6

Short form:
let multiply = (a, b) => a * b;
console.log(multiply(2,3));//6

4)function with parameter
-A function that accepts values (parameters) when called
-Example:
function square(n) {
    console.log(n * n);
}
square(4);// 16


5)function with return value
-A function that returns a result using return
-Example:
function sum(a, b) {
    return a + b;
}
let result = sum(10, 20);
console.log(result);// 30

6)immediately invoked function
-A function that runs immediately after it is defined
-Example:
(function () {
    console.log("I am executed immediately");
})();

7)call back function
-A function passed as an argument to another function and executed later
-Example:
function display(result) {
    console.log(result);
}
function calculate(a, b, callback) {
    let sum = a + b;
    callback(sum);
}
calculate(5, 10, display);//15

8)recursive function
-
-Example:
function factorial(n) {
    if (n === 0)
        return 1;
    else
        return n * factorial(n - 1);
}
factorial(5);// 120
